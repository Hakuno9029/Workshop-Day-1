# Snip

Snip is a tiny URL shortener with one backend and two clients: an Angular web
app and a Node.js CLI. The backend owns the API and in-memory link store; both
clients consume the same records.

## Repository layout

`main` is the superproject. `backend`, `frontend`, `cli`, and generated `bundle`
are submodules, each pinned to a commit on its matching branch. Clone with
`git clone --recurse-submodules https://github.com/Hakuno9029/Workshop-Day-1.git`.
A plain clone leaves the submodule directories empty; populate them with
`git submodule update --init --recursive`.

## API

| Method | Path | Request | Response |
| --- | --- | --- | --- |
| `POST` | `/api/links` | `{"url":"https://example.com"}` | `201` link object; `400` with `{error}` for invalid input |
| `GET` | `/api/links` | — | `200` array of link objects |
| `GET` | `/:code` | — | `302` redirect and hit increment; `404` for an unknown code |

Each link contains `code`, `url`, `shortUrl`, `hits`, and `createdAt`. Links are
stored in memory and are cleared when the backend restarts.

## Run from a recursive checkout

Start the backend in one terminal with `cd backend` then `bun start`.
Start the web app in another with `cd frontend`, `npm ci`, then `npm start`.
Use the CLI from a third terminal with `cd cli`, then `node cli.js help`.
The development server proxies API calls to the backend on port 3000.

The generated release in `bundle` serves the UI, API, and redirects from one
Bun process. See `scripts/build-bundle.mjs` to rebuild it.

## Updating a component

Commit and push changes from inside the component submodule. Then, from the
superproject, run `git submodule update --remote <path>`, stage that submodule
path, commit the new pointer, and push `main`. For example:
`git submodule update --remote backend && git add backend`.

The bundle is generated by `node scripts/build-bundle.mjs`; pass `--push` to
publish its branch and the updated `main` pointer. GitHub Actions also rebuilds
it hourly and publishes a GHCR Docker image when the pinned bundle changes.
Set `main` as the repository's default branch for the hourly schedule. Image
publishing is gated by the dependency audit and a Trivy scan; high or critical
findings stop the release.
